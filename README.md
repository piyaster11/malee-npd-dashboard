# Unofficial NPD market dashboard (public sources)

Single-file static dashboard (`index.html`, EN/ไทย toggle, no external scripts). Unofficial, independent analysis built from public sources. **Not a Malee publication**; not reviewed or confirmed by Malee Group.

## What is real and what is sample
- **Market insights** tab: real public data. Each item is labelled real / estimate / not found, with its source and date.
- **All other tabs**: SAMPLE data to show how the tools work. Not real company numbers.

## Method notes
- Trend = search interest, not sales. Google scales each term to its own peak, so % changes for low-volume terms are noisy. Terms with too little search volume are shown as "too few searches", never estimated.
- Some launch search terms are broad (for example a brand name alone) and are not product-specific.
- No private, internal or personal data is included. Thai text is machine-written.
